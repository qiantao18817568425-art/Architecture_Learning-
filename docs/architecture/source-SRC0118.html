data_profile与 pcm_profile的应用
前提：相同时间内，
pcm_profile 与
 data_profile 消耗的数据量一致。
应用目的：弥补硬件声道数不足的问题
应用一：通过将32Bit降为16Bit来提升声道数
优点：采样率不变，不需要 Codec（ADC/DAC）或外置 ADSP 做特殊的适配修改
缺点：只能传16Bit/Channel，精度会有损失
xml 配置举例：I2S6 (
48K
*
8ch
*
32bit) -> AFE CM -> HAL (
48K*16ch*16bit)
每帧数据都一样大：8ch * 32bit / 8 = 32 Bytes = 16ch * 16bit / 8
